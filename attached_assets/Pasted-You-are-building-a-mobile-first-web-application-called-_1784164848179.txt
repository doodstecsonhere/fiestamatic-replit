You are building a mobile-first web application called "Fiestamatic". 
Tagline: "Basta fiesta, 'matic na!"
Purpose: A Dumaguete City fiesta navigator app that promotes local tourism, education, neighborliness, and community social bonds (bayanihan).

Tech Stack: React, Tailwind CSS, Lucide React (icons), and Leaflet (OpenStreetMap) for mapping (do not use Google Maps to avoid API key blockers).

CORE FEATURES REQUIRED:
1. Dynamic Countdown & Chronological Sorting: The home screen must display an auto-sorting dashboard showing the closest upcoming barangay fiestas based on the current date. 
2. Interactive Map: A map plotting all barangays. Tapping a pin reveals a quick card with the fiesta date and an action button to navigate to the location.
3. Search & Filter: Users can search by Barangay name or filter by "Happening this Month", "Upcoming", or "Poblacion vs Outer Barangays".
4. Educational Drawer (Optional Component): Clicking a Barangay card opens a beautiful slide-up bottom drawer. It displays:
   - Barangay Name, Fiesta Date, and Hall Coordinates.
   - A section for "Name Origin" (Placeholder text to be filled later).
   - A section for "Patron Saint & Traditions" (Placeholder text to be filled later).
5. Bayanihan Community Board: A dedicated tab for "Fiesta Carpooling & Shared Tables" to encourage neighborly connection, coordinate visits, and foster local community relationships.

---
CRITICAL ARCHITECTURAL REQUIREMENT (Date Normalization Engine):
The data contains floating dates (e.g., "May 1st Saturday", "January 3rd Sunday") and dual dates ("April 5 or October 7"). 
You MUST implement a JavaScript utility function (`getOrCreateFiestaDate(fiestaString, currentYear)`) that parses these strings into concrete JavaScript Date objects for the current calendar year, allowing the app to successfully sort the timeline chronologically and calculate accurate countdowns (e.g., "Happening in 4 days").
